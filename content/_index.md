Tell the composer how many Voltras you have, whether you have the Travel Platform, which handles you own and where
you can anchor. It shows only the exercises your setup allows and builds a balanced workout, which you can run in
the Tabata or interval timer.

I built this to plan my own sessions with the Beyond Power VOLTRA I. It isn't an official Beyond Power site.
